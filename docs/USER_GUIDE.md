# Linkcho Desktop 用户手册

## 1. 建立词库

在“词库管理”页导入 Excel 或 CSV。程序读取第一列，仅接受纯英文单词；包含空格、连字符或标点的内容会进入隔离区。智能追加会保留学习进度，清空覆盖会要求先导出备份。

## 2. 回填词义

在“API 与模型设置”中保存兼容服务配置，然后点击“一键 AI 解析未回填单词”。任务只处理核心字段缺失的记录，可随时取消，已完成批次会保留。

## 3. 维护词库

- 使用搜索框查询单词、释义或备注。
- 双击可编辑字段并自动保存。
- 点击“音标 🔊”播放美式发音。
- 批量删除时以复选框为准；没有勾选时删除当前单行。
- `status = -1` 表示归档，`0` 表示未使用，正数表示进入故事的次数。

## 4. 生成播客

切换到“播客创作”，选择预设风格，也可输入人物、场景和语气要求。系统抽取 50 个候选词，由 AI 选取至少 25 个融入短故事。

## 5. 历史库与音频

历史库中可搜索、删除、生成音频或下载 MP3。点击“播放”会在同一个历史库窗口进入双语播放页；点击“返回剧本库”回到原列表。

播放时中英文句子会按进度高亮并滚动。点击英文加粗生词可在主词库定位对应记录，播放器不会关闭。

## 6. 备份

定期使用“导出当前词库”保存 CSV。执行清空覆盖导入前，程序会强制要求先备份。
